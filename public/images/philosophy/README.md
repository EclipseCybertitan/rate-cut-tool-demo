## 设计规范
- **统一风格**: 电幻霓虹赛博风
- **发光效果**: 边缘轻度发光描边
- **色彩搭配**: 霓虹蓝紫/青绿/金色点缀
- **图片质量**: 高清PNG格式，支持透明背景
- **文件大小**: 建议小于 300KB

## 替换方法
1. 将新图片放入 `public/images/philosophy/` 文件夹
2. 保持文件名不变
3. 确保图片风格与整体界面协调
4. 图片会自动应用到对应的投资哲学卡片中
